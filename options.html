My PRs Tab Group

Keeps one tab group filled with the open pull requests you authored on GitHub. Merged and closed PRs leave the group on the next sync.

GitHub access

Opens github.com in a new tab, where you're already signed in. Approve the code shown here and you're done.

If an org limits third-party apps, its PRs stay hidden until an org owner approves the app. A personal access token below has no such limit: it reaches every repo you can.

Create a classic token with the repo scope, which covers private repos. A fine-grained token works too: give it the repositories you work in, with Pull requests and Metadata set to read-only. If your org uses SAML SSO, authorize the token for that org on GitHub, or its PRs won't show up.

Either way, the token is kept in this browser's local extension storage and is sent only to api.github.com.
